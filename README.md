# Les Carnets de Léka — historique public du développement

Ce dépôt sert à suivre **l’évolution du code, les corrections de bugs et les décisions techniques** des Carnets de Léka.

Il ne publie pas le site complet. L’objectif est d’avoir un historique lisible de ce qui a changé, pourquoi cela a changé et, quand cela est utile, quelles parties du code ont été touchées.
Le site est actuellement 99% statique en Html5/Css3 & Js, une toute petite branche en PHP sans base de données. 
On use du localstorage, du navigateur de l'internaute :)

## Lire l’historique

- [`EVOLUTION-CODE.md`](EVOLUTION-CODE.md) : vue d’ensemble par grandes phases du développement
- [`CHANGELOG.md`](CHANGELOG.md) : journal complet, version par version 
- [`HISTORIQUE-DATE.md`](HISTORIQUE-DATE.md) : chronologie compacte avec les dates 
- [`historique/`](historique/) : une fiche détaillée par version, de V93 à V165 
- [`patches/`](patches/) : différences de code publiées lorsque celles-ci sont disponibles et adaptées à un dépôt public.

## Principe

L’historique décrit les corrections elles-mêmes, pas les anciens fichiers de livraison. Les versions documentaires, comme les audits SEO, sont signalées comme telles afin de ne pas les confondre avec une modification du code.

V93 est la première base complète encore conservée. Sans version antérieure exploitable, les changements précédant V93 ne sont pas reconstruits artificiellement.
