# Les Carnets de Léka — correctifs publics

Ce dépôt est volontairement **limité aux correctifs**.
Pour le contenu global, il peut être mis à disposition sur demande (je me réserve le droit de refuser en fonction du projet)

Le code source complet du site, les contenus, les médias et les fichiers de production ne sont **pas publiés ici**.

## Contenu

- `patches/` : fichiers `.patch` montrant uniquement les différences entre deux versions.
- `CHANGELOG.md` : historique détaillé et daté des corrections publiées.
- `HISTORIQUE-DATE.md` : index chronologique compact.
- `historique/` : manifests publics des fichiers concernés par chaque version historique.
- `GITHUB-PROCEDURE.md` : procédure pour publier ce dépôt sans exposer le site complet.

## Politique de publication

Chaque version publique doit contenir uniquement :

1. un résumé du correctif ;
2. le patch correspondant ;
3. éventuellement une note technique sans données privées.

Ne jamais ajouter dans ce dépôt : le dossier complet du site, des sauvegardes, des fichiers `.env`, des identifiants, des clés API, des bases de données, des fichiers de configuration privés ou des médias personnels non destinés à être publics.


## Historique consolidé

L’historique public couvre maintenant les archives conservées de V93 à V165. Les anciennes versions sont documentées par des manifests de chemins et de métadonnées afin de ne pas republier le code complet du site.
